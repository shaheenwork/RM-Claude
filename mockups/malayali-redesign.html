Visual redesign · mockup for approval

A connection app for Malayalis എവിടെയും

Kerala-rooted, worldwide-warm.

This is a cosmetic / styling pass only — no features, logic, routing, or component structure change. The direction nods to Kerala through light and warmth (a brass nilavilakku glow, the gold kasavu thread, backwater greens, kasavu-cream surfaces) rather than literal motifs like houseboats or elephants. The connection moment uses a brass lamp core orbited by people on faint globe arcs — a quiet "Malayalis everywhere" cue for the diaspora. Both dark and light modes are shown since the app is used at every hour, in every timezone.

Open question for you: the app is currently branded “StrangerChat” and addresses the user as “stranger.” For a Malayali-only app I’ve softened this to “Anonymous Malayali” and a warm Namaskaram greeting in the mockup. I did not rename the app itself — tell me if you want a new wordmark, or to keep “StrangerChat.”
01

Design language

Palette is split by role so it never feels busy: brass/gold = brand, primary CTA, the lamp, the kasavu thread; teal-green = connection, live status, your own messages; terracotta used sparingly. Type pairs a clean Latin UI face (Inter) with a serif-italic for emotional accents, and a subtle Malayalam face (Manjari) for the logo / greeting only.

Signature — the kasavu thread

A single fine gold line, borrowed from the gold border of a Kerala mundu/sari. Used as a divider, card edge, and active-tab marker — recognisably Kerala without a single literal graphic.
