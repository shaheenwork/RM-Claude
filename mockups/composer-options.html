My take

Option A wins for chat apps with media + voice. Telegram, Signal, and Threads use this. Mic stays one-tap for the most-used media action. Camera/GIF in a sheet feels organized, not cluttered.

Avoid Option B — inline icons fight with the text cursor. Avoid Option D — wastes vertical space, the secondary row gets ignored. Option C is fine but the plus button adds a click before media.
