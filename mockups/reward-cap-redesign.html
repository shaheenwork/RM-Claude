Rewarded-ad daily cap സൗജന്യം

Cap = 3 ads / day. Cooldown = 30 min between earns. When cap reached, the same surface morphs into a brass Upgrade for unlimited upsell — same component, state-driven render. No new screens, no flow changes.

Two surfaces affected: the Home RewardsCard and the Chat AttachSheet "Watch Ad" tile. A third optional surface — a confirmation bottom-sheet — is shown only if the user taps a stale Watch-Ad CTA right as the cap flips.

Why this sheet mattersConversion lever

The bottom sheet fires at the moment of denied access — psychologically the strongest premium-upsell trigger in any freemium app. The user has clear intent (wanted media), faces a wall, and is offered the exact unlock. Conversion at this moment is typically 5–15× higher than passive home-screen upsell.

The static RewardsCard already mutates to "Upgrade" at cap — so most users see the offer there first. This sheet is the fallback for edge cases (e.g., user taps the tile in chat the moment cap flips). Without it, taps go to a silent no-op → friction → uninstall risk.

Copy is framed as a choice, not a hard wall ("Cancel anytime · Resets at midnight if you wait") — avoids the "trapped" feeling that gets 1-star reviews.

4. State machine (single source of truth)

Both surfaces subscribe to the same StateFlow<RewardGate>. UI just renders the current state — no per-surface logic.

sealed class RewardGate {
    data class Ready(val watchesLeft: Int) : RewardGate()        // user can earn now
    data class Cooldown(val secondsLeft: Long) : RewardGate()    // earned recently
    data object CapReached : RewardGate()                        // hit daily 3
}

// SessionManager
suspend fun getRewardGate(): RewardGate {
    rolloverIfNewDay()
    val left = DAILY_REWARD_CAP - rewardEarnsToday
    if (left <= 0) return RewardGate.CapReached
    val sinceLast = System.currentTimeMillis() - lastRewardEarnMs
    if (sinceLast < COOLDOWN_MS) return RewardGate.Cooldown((COOLDOWN_MS - sinceLast) / 1000)
    return RewardGate.Ready(left)
}

suspend fun recordRewardEarn() {
    rolloverIfNewDay()
    rewardEarnsToday += 1
    lastRewardEarnMs = System.currentTimeMillis()
    addRewardedMediaCredits()   // +1 photo / +1 voice / +1 gif
}
