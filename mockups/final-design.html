StrangerChat — Final Design

Midnight Subdued direction, age 20-40 calibrated. Every existing screen below. No code changes yet — review and approve before Phase 2.

0. Design System

Midnight Subdued — pink-purple base desaturated ~20% from neon. Electric blue + ember amber as functional accents. Instrument Serif (italic headlines) + Inter (body). Sentence case microcopy. Selective italics for emotional weight.
