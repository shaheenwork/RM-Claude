Identity system

Mask: emoji avatar — user picks from a curated set (moon/wave/fire/eye/etc). Changeable but persistent enough for streak feel.

Display name: auto-generated poetic single word (moonlight, drift, ember, mist). User can shuffle.

Anon ID: 6-character hex. Stays constant. Used for "block" + match-history without revealing identity.

Vibes: 3 tags max. Match algorithm prioritizes shared vibes.

Badges: earned via behavior. Night Owl = chats after midnight. Listener = strangers reacted ❤️ multiple times. 100 Chats = quantity. Locked badges hint at future rewards → curiosity loop.

Stats visible to YOU only — not to strangers. Keeps anonymity intact.

7. Typography — Instrument Serif + Space Grotesk

Display in Instrument Serif (italic for emotional weight). Body in Space Grotesk (modern geometric, premium). The combination = "premium magazine app", not "tech bro SaaS".

stranger
Space Grotesk for body — modern, geometric, premium. Reads at small sizes too. Instrument Serif for emotional headlines — italic adds intimacy.
"someone interesting is online tonight" — Instrument Serif italic, accent pink
Why this pairing: Modern Gen Z apps (Bereal, Locket, Threads) lean into editorial serifs for the headline-emotion moment. The italic in "stranger" or "someone" or "interesting" is the signature trick — it makes one word feel personal. Space Grotesk body keeps the rest functional.

8. Retention Features — Dopamine Loop

Visual ideas. Each one is a separate addictive loop layered on top of the chat experience.

🔥

Streak System

Daily chat streak with flame counter. 7-day milestone unlocks rare avatar. 30-day = "Devoted" badge. Streak freeze = premium perk.

💌

Re-engagement DMs

"Someone you chatted with last week is online now" — push notif with a faded avatar tease. Strong return trigger.

🌙

Night Mode Boost

10pm-3am window shows "Late Night Crew" badge in matching. Special palette tint. Capitalizes on peak-emotion hours.

✨

Mystery Box

Random reward after every 5 chats: rare avatar, free premium hour, vibe unlock. Variable reward = dopamine king.

👁

Who's Watching

"3 strangers viewed your vibe before you matched" — social validation trigger after each chat ends.

📈

Vibe of the Night

Daily live counter: "Tonight 67% chose Flirty". Creates FOMO + shifts user behavior. Updates in real time.

💎

Premium Glow

Premium users get a subtle gradient ring around their mask in chat. Visible but tasteful flex → drives upgrades.

🎭

Avatar Evolution

Your mask emoji subtly animates after 50 chats (sparkles around it). Triggers "what happens at 100?" curiosity.

🔔

"Someone's typing about you"

If a previous stranger opens app and remembers you (rare), notif fires. Massive emotional pull. Builds returning behavior.
