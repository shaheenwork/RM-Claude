How they differ —
A · Cinematic Narrative (recommended): emotional hook line + serif accent + one hero visual per page. Premium woven into a real chat snippet, not a sales grid. Warmest, most "premium app" feel — fits the 20-40 audience.

B · Live Product Demo: shows the actual match screen, a real chat, and the real report sheet. Highest information transfer, lowest abstraction — best if you want users to *recognize* the UI before using it.

C · Editorial Minimal: 2-3 words, giant serif, max whitespace. Fastest to skip through, boldest voice — riskiest (teaches least).

All three drop the old generic feature-grid Premium page, keep Skip + dot indicators + gradient CTA, reuse the exact Midnight palette & serif-italic display.
